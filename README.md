# Experiment 2: Creating a Forensic Image Using Guymager

## Aim
To create a forensic disk image of a storage device using Guymager.

## Tool Used
Guymager

## Procedure
1. Open Guymager in a supported Linux environment.
2. Select the test storage device.
3. Choose the Acquire Image option.
4. Select the Linux DD (raw) image format.
5. Specify the output filename and destination.
6. Start the acquisition process.
7. Verify the acquisition status and hash values, if available.

## Output
Screenshots of the Guymager interface and the forensic image acquisition process are provided in this repository.

## Result
The forensic imaging procedure was studied using Guymager. Actual acquisition results will be documented after completing the experiment.
